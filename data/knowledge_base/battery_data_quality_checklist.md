# Battery RUL Data Quality Checklist

배터리 잔여수명 예측을 시작하기 전에 배터리 단위로 실험 조건과 시계열 품질을 확인해야 한다. 서로 다른 실험 조건과 열화 패턴을 그대로 섞으면 모델이 배터리의 열화 특성보다 실험 환경의 차이를 먼저 학습할 수 있다. 따라서 전체 데이터를 무작정 사용하는 것보다 그룹 차이, 데이터 누수 가능성, 초기 관측 비율, 배터리 단위 검증 구조를 함께 고려해야 한다.

## Cycle sequence

각 배터리의 cycle 번호가 단조 증가하는지, 누락되거나 중복된 cycle이 있는지 확인한다. 초기 cycle 기반 RUL 예측에서는 같은 battery의 앞뒤 cycle이 학습과 검증에 섞일 경우 데이터 누수가 발생할 수 있으므로, 평가 목적에 맞게 battery-level split이나 support/query 구성을 명확히 기록해야 한다.

## Capacity and sensor features

Capacity는 열화 추세를 확인하는 핵심 지표다. 전압, 전류, 온도, 임피던스 계열 feature는 결측값, 비정상 범위, 급격한 변화가 있는지 함께 점검한다. 이상값을 무조건 제거하기보다 측정 오류인지 실제 열화 신호인지 구분해야 한다.

## Early prediction

실제 운영 환경에서는 새 배터리의 전체 수명 데이터를 미리 확보할 수 없다. 따라서 초기 일부 cycle만 관측한 조건에서 장기 RUL을 예측하는 평가 시나리오가 필요하다. 관측 비율과 support/query 구성을 명시하면 실험 결과를 재현하고 비교하기 쉽다.
