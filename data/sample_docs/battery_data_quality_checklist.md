# Battery RUL Data Quality Checklist

배터리 잔여수명 예측을 시작하기 전에 배터리 단위로 실험 조건과 시계열 품질을 확인해야 한다. 서로 다른 온도 조건, 충방전 프로토콜, 측정 간격을 그대로 섞으면 모델이 열화 패턴보다 실험 환경의 차이를 먼저 학습할 수 있다.

## Cycle sequence

각 배터리의 cycle 번호가 단조 증가하는지, 누락되거나 중복된 cycle이 있는지 확인한다. 데이터 분할은 행 단위 무작위 분할보다 배터리 단위 분할을 우선한다. 같은 배터리의 초기 cycle과 후반 cycle이 학습셋과 검증셋에 함께 들어가면 데이터 누수가 발생할 수 있다.

## Capacity and sensor features

Capacity는 열화 추세를 확인하는 핵심 지표다. 전압, 전류, 온도, 임피던스 계열 feature는 결측값, 비정상 범위, 급격한 변화가 있는지 함께 점검한다. 이상값을 무조건 제거하기보다 측정 오류인지 실제 열화 신호인지 구분해야 한다.

## Early prediction

실제 운영 환경에서는 새 배터리의 전체 수명 데이터를 미리 확보할 수 없다. 따라서 초기 일부 cycle만 관측한 조건에서 장기 RUL을 예측하는 평가 시나리오가 필요하다. 관측 비율과 support/query 구성을 명시하면 실험 결과를 재현하고 비교하기 쉽다.
